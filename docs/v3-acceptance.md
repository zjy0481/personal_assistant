# V3 验收清单：日报助手联网问答

> 状态：待验收
>
> 对应需求：`docs/v3-requirements.md`

## 自动验收

- [ ] 现有后端测试全部通过，不依赖真实 API Key 或真实外部网络。
- [ ] 新增单元测试覆盖：联网触发条件、搜索轮次上限、网页读取上限、请求超时、失败重试、每日限额、缓存 TTL、黑名单和 SSRF 安全校验。
- [ ] 新增单元测试覆盖：DeepSeek Responses API 适配、网页正文提取、来源引用持久化和会话上下文构建。
- [ ] 新增前端测试或静态检查：网页端聊天开关、联网状态提示、来源卡片、流式回答和搜索失败提示。
- [ ] 配置校验测试覆盖：`web_search_enabled=false`、模型切换、超时/轮次/缓存/每日限额的非合法值。

## 网页端人工验收

- [ ] 默认开启联网，问答面板显示会话级“联网搜索”开关。
- [ ] 查询“今天有什么值得关注”等实时问题，能显示“正在联网检索”状态并返回带来源的回答。
- [ ] 查询“昨天日报里的天气如何”等本地问题，不触发不必要的联网搜索。
- [ ] 回答中的来源以可点击标题和 URL 展示，点击后能打开原始页面。
- [ ] 用户输入一个公网 URL 后，助手能读取正文并基于页面内容回答。
- [ ] 切换到“关闭联网”后，不再发起外部搜索，回答仍可基于本地日报信息。
- [ ] 模拟搜索失败或超时，页面出现“联网检索失败”提示，并返回可用的本地降级回答。
- [ ] 模拟每日联网上限，达到后回答明确提示联网已暂停，并降级为离线回答。
- [ ] 网页端回答为流式输出，整个请求在 60 秒上限内完成或按失败流程结束。
- [ ] 1280px 与 375px 宽度下，聊天面板、来源卡片和状态提示无布局溢出。

## 企业微信人工验收

- [ ] @ 智能机器人触发默认自动联网问答，并返回中文回答与来源链接。
- [ ] 输入“联网：xxx”或“搜索：xxx”可强制联网。
- [ ] 输入“不联网：xxx”或“离线：xxx”可强制离线回答。
- [ ] 搜索失败时，机器人返回降级回答，并明确提示联网检索失败。
- [ ] 回复开头标记“已联网检索”，末尾最多列出 3 条来源链接。
- [ ] 9000 字符以上的长回答得到合理截断，来源链接仍可访问，不被截断成残缺 URL。
- [ ] 同一群聊消息不会重复回复，断线后可自动重连。

## 安全验收

- [ ] `localhost`、`127.0.0.1`、`10.x.x.x`、`192.168.x.x`、`172.16-31.x.x`、IPv6 环回和链路本地地址被拒绝。
- [ ] `file://`、非 HTTP(S) 协议和其他非公网目标被拒绝。
- [ ] 外部请求重定向到受限地址时被拒绝，DNS 解析结果不会绕过校验。
- [ ] 响应体超过大小上限、内容类型不受支持时，返回可诊断错误而非崩溃。
- [ ] 黑名单域名被拒绝，且配置文件中不暴露真实密钥。
- [ ] 外部请求不携带本地 `.env` 中任何凭证。

## 配置与部署验收

- [ ] 本地环境不配置代理也能完成联网问答。
- [ ] 服务器可通过可选 `http_proxy`/`https_proxy` 配置使用代理，默认关闭。
- [ ] `web_search_enabled=false` 时，网页端和企业微信都不发起外部搜索。
- [ ] 部署文档说明 V3 开关、限额、缓存和黑名单配置方式。
- [ ] 服务器按“先网页端验证、再企业微信验证”的顺序上线，出现故障可立即关闭全局开关。
- [ ] V3 主 Issue、`docs/v3-requirements.md`、`docs/v3-acceptance.md` 和 ADR-0005 均已存在且内容一致。
