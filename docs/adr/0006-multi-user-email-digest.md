# 多用户数据隔离、加密凭据与邮件简报架构

- 状态：已接受
- 日期：2026-09-07

V4 将个人助手从单用户扩展为多用户，并新增邮件简报与追踪内容。决定以服务端用户会话为所有数据的唯一归属，用户账户不由前端创建；密码使用 Argon2id 哈希，邮件凭据使用 Fernet 加密；邮件通过 IMAP 拉取、正文纯文本加密存储，并由共享 LLM 服务评分后生成与日报分离的简报。

选择服务端会话而非前端 token，是因为多用户数据需要可靠的用户身份和可撤销会话；选择 Argon2id 与 Fernet，是因为用户密码和邮件凭据属于高敏感数据，不能明文落库。选择 IMAP 增量同步而非邮件 API 转发，是因为需要覆盖 QQ、163、Outlook 等不同服务商，且不需要用户暴露完整邮箱授权给第三方。

## 影响

- 新增两个安全依赖和两个服务端密钥；密钥丢失会导致历史邮件凭据不可恢复。
- 现有日报、收藏、趋势、预警、聊天等数据必须迁移到首次用户，部分表需要补充 `user_id`。
- 日报调度和邮件简报调度都要改为按启用用户遍历，避免用户间相互影响。
- 邮件简报采用“通知只提示网页查看”的边界，避免在群聊推送中泄露邮件内容。
- 企业微信智能机器人 userid 与内部用户映射暂不纳入 V4，后续单独实现。
