# 企业微信群机器人作为 V1 主推送渠道，PushPlus 作为备用渠道

- 状态：已接受
- 日期：2026-09-01
- 取代：ADR-0003（PushPlus 作为 V1 主推送渠道）

## 背景

在实际使用中，企业微信群机器人 Webhook 已稳定用于日报和极端天气预警推送，
不需要额外的手续即可向已加入的群发送消息。PushPlus 依赖微信服务号、实名认证
和用户 token，更适合作为可用性冗余，而不是默认首选。

## 决策

1. 推送渠道默认顺序调整为 `["wecom_group", "pushplus"]`。
2. 企业微信群机器人 Webhook 是日报和预警的主渠道。
3. PushPlus 作为备用渠道，在企业微信群机器人失败时继续尝试。
4. `push_channels` 仍保持顺序列表语义，后续调整无需修改适配器。
5. 项目文档、配置模板和测试均以“企业微信群机器人主、PushPlus 备”为当前口径。

## 影响

- 新环境无需 PushPlus 实名认证也能完成主推送。
- 企业微信群机器人仍要求有效且当前可用的 Webhook 密钥。
- 历史 ADR-0003 仅保留为决策记录，不再作为当前默认行为。
