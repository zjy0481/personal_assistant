# V4 验收清单：多用户、邮件简报与追踪内容

> 状态：待验收
>
> 对应需求：`docs/v4-requirements.md`

## 自动验收

- [ ] 用户表、会话表、用户设置表、邮件账户、邮件、排除规则、追踪内容、邮件简报相关表均在测试数据库创建。
- [ ] 用户名或邮箱重复、密码策略、用户停用、登录频率限制均有单元测试。
- [ ] 密码哈希和邮件凭据加密/解密测试通过，测试夹具不使用真实密钥。
- [ ] `user add/list/reset-password/enable/disable/bootstrap` 均有 CLI 测试和幂等测试。
- [ ] `default` 数据迁移测试覆盖报表、收藏、趋势、预警、聊天、企微消息和消息表。
- [ ] IMAP 适配器、MockTransport、增量 UID、Message-ID 去重、首次同步与账户测试连接均有测试。
- [ ] 排除规则命中、LLM 评分 JSON、评分失败降级、追踪命中与最终分数公式均有测试。
- [ ] 简报生成、无邮件跳过、部分账户失败、每日调度遍历和通知固定文案有测试。
- [ ] 页面和 API 均验证当前用户隔离，跨用户读取返回空或 404。

## 人工验收

- [ ] 登录页无注册入口，用户名或邮箱均可登录；错误密码提示不泄露用户是否存在。
- [ ] 会话失效后自动跳转登录；退出登录后旧 Cookie 不可继续访问。
- [ ] 运行 `user add` 在服务器创建用户，`list` 能显示状态，`reset-password` 后新密码可登录。
- [ ] 运行 `user bootstrap` 后首次用户可登录，旧 `default` 日报、收藏、趋势、预警和聊天仍在。
- [ ] 个人设置页可修改时区、地区、时间、通知渠道；修改后定时任务按新配置运行。
- [ ] 邮箱账户可新增、编辑、软删除、永久清除和测试连接；页面不显示已保存密码。
- [ ] 首次同步后简报页能查看 7 天内邮件；同一封邮件不会重复出现。
- [ ] 手动生成简报后，Top 20、排除、评分、追踪提升和降级标记符合配置。
- [ ] 邮件账户失败时，其他账户邮件仍能生成部分简报。
- [ ] 无新邮件时不生成简报、不发送通知。
- [ ] 通知只包含“邮件简报已生成，请前往网页端登录查看”和链接，不包含邮件正文。
- [ ] 追踪管理页新增、编辑、删除、权重和启用状态均生效；从简报点击“追踪该邮件”后生成正确规则。
- [ ] 邮件正文在服务器数据库中以密文保存，删除用户/账户的永久清除操作有二次确认和审计记录。
- [ ] 1280px 与 375px 宽度下登录、设置、账户、追踪、简报页面无布局溢出。

## 安全与迁移人工验收

- [ ] `SECRET_KEY`、`ENCRYPTION_KEY` 存在于服务器 `.env` 且权限为 600。
- [ ] 数据库迁移前自动产生时间戳备份，备份文件可恢复。
- [ ] 迁移命令重复运行不会重复创建用户或重复迁移数据。
- [ ] 密钥缺失时命令拒绝执行，并给出明确提示。
- [ ] 恢复数据库备份和服务旧归档后，系统可回到迁移前状态。
- [ ] V4 完成后，旧全局 token 兼容层可按部署文档关闭。
